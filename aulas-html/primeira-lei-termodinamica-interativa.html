02 • Considerações preliminares

Três ideias que não podem se confundir

Calor e trabalho são formas de transferência de energia. Energia interna é uma propriedade do estado do sistema.

Q

Calor

Energia transferida por diferença de temperatura.

⇄
ΔU

Energia interna

Energia microscópica associada ao estado do gás.

⇄
W

Trabalho

Energia transferida quando o gás move o meio externo.

Q > 0

O gás recebe calor.

W > 0

O gás se expande e realiza trabalho.

ΔU > 0

A energia interna aumenta; para gás ideal, isso significa aumento de temperatura.

Regra conceitual: não diga “o corpo possui calor” ou “possui trabalho”. O sistema possui energia interna; calor e trabalho descrevem energia em trânsito.
03 • Trabalho numa transformação

O gráfico p × V mede trabalho por área

Para pressão constante, o trabalho do gás é W = p·ΔV. Em transformação qualquer, a área sob a curva representa numericamente o trabalho.

W = p · ΔV = p(Vf − Vi)

Expansão

Vf > Vi → W > 0

Compressão

Vf < Vi → W < 0

Isocórica

ΔV = 0 → W = 0

Em SI, 1 Pa·m³ = 1 J. Uma equivalência prática útil no simulador: 1 kPa·L = 1 J.
04 • Conservação da energia

A Primeira Lei da Termodinâmica

Com a convenção pedida nesta aula — W é o trabalho realizado pelo gás — a variação de energia interna é o calor líquido recebido menos o trabalho realizado.

ΔU = Q − W
Q

Entrada térmica

Q > 0 quando o gás recebe calor; Q < 0 quando cede calor.

W

Trabalho do gás

W > 0 na expansão; W < 0 na compressão.

ΔU

Saldo interno

ΔU > 0 quando a energia interna final é maior.

Lei de Joule para gases ideais: a energia interna depende da temperatura. Para um gás ideal monoatômico, U = 3/2 nRT e ΔU = 3/2 nRΔT.
Função de estado: entre os mesmos estados inicial e final, ΔU é a mesma, ainda que o caminho no diagrama p × V seja diferente. Já Q e W dependem do processo.
Cheque os sinais
350 J
O gás recebe 600 J, usa 250 J para realizar trabalho e armazena 350 J como aumento de energia interna.

Isotérmica • desenvolvimento

T constante

ΔT = 0
gás ideal: ΔU ∝ ΔT ⇒ ΔU = 0
ΔU = Q − W ⇒ 0 = Q − W
Q = W

Como pV = nRT e T não muda, pV = constante. O gráfico p × V é uma hipérbole.

Isobárica • desenvolvimento

p constante

W = pΔV
Q = nCpΔT
pΔV = nRΔT
ΔU = Q − W = n(Cp − R)ΔT

Com Cp − Cv = R, resulta ΔU = nCvΔT. Em expansão aquecida, Q > W.

Isocórica • desenvolvimento

V constante

ΔV = 0 ⇒ W = 0
Q = nCvΔT
ΔU = Q − 0
ΔU = Q

No gráfico p × V, o processo é vertical. Não existe área sob deslocamento em V; por isso o trabalho é nulo.

Adiabática • desenvolvimento

Q = 0

Q = 0
ΔU = Q − W ⇒ ΔU = −W
pVγ = constante
γ = Cp/Cv

Expansão: W > 0 ⇒ ΔU < 0 ⇒ T diminui. Compressão: W < 0 ⇒ ΔU > 0 ⇒ T aumenta.

Calores molares

Qp = nCpΔT
Qv = nCvΔT

Para uma mesma elevação de temperatura, em geral Qp > Qv, porque na isobárica o gás também realiza trabalho.

Relação de Mayer

Cp − Cv = R

A diferença entre os calores molares a pressão e a volume constantes é a constante universal dos gases.

Adiabática × isotérmica

Partindo do mesmo estado, a curva adiabática é mais íngreme. Na expansão adiabática, a pressão cai mais rapidamente porque o gás também esfria.

Expoente de Poisson

γ = Cp/Cv

Ele aparece na lei de Poisson: pVγ = constante.

07 • Transformação cíclica

Num ciclo, ΔU = 0. O que sobra é Q = W.

O sistema retorna ao estado inicial. Como a energia interna é função de estado, sua variação total é nula. O trabalho líquido é a área algébrica interna ao ciclo.

Sentido do ciclo
Wciclo > 0 → Qciclo > 0
No sentido horário, o trabalho total realizado pelo gás é positivo. Ao final do ciclo, o gás recebeu calor líquido igual a esse trabalho.

08 • Exemplos de aplicação

Resolução construída passo a passo

Use “Próximo passo” para conduzir a turma sem entregar tudo de uma vez. Os valores são exemplos autorais alinhados ao conteúdo do capítulo.

Exemplo 1 • Primeira Lei

Calor recebido e trabalho de expansão

Um gás recebe 900 J de calor e realiza 350 J de trabalho. Determine a variação da energia interna.

1. Convenção: Q = +900 J e W = +350 J.
2. Primeira Lei: ΔU = Q − W.
3. ΔU = 900 − 350 = 550 J.
Resposta: ΔU = +550 J. A energia interna aumentou.
Exemplo 2 • Isobárica

Trabalho no diagrama p × V

Sob pressão constante de 150 kPa, um gás passa de 2,0 L para 5,0 L. Calcule W.

1. ΔV = 5,0 − 2,0 = 3,0 L.
2. W = pΔV.
3. Como 1 kPa·L = 1 J: W = 150 × 3,0 = 450 J.
Resposta: W = +450 J, pois houve expansão.
Exemplo 3 • Isocórica

Aquecimento sem movimento do êmbolo

Um gás em recipiente rígido recebe 1,2 kJ de calor. Qual é ΔU?

1. Recipiente rígido → ΔV = 0.
2. Logo, W = 0.
3. ΔU = Q − W = 1200 − 0.
Resposta: ΔU = +1,2 kJ.
Exemplo 4 • Adiabática

Trabalho sem troca de calor

Em uma expansão adiabática, o gás realiza 500 J de trabalho. Determine Q e ΔU.

1. Adiabática → Q = 0.
2. Expansão → W = +500 J.
3. ΔU = Q − W = 0 − 500 = −500 J.
Resposta: Q = 0 e ΔU = −500 J; a temperatura diminui para gás ideal.
09 • Prática guiada

Construa o balanço energético

Escolha Q e W. O painel calcula ΔU e interpreta o que ocorreu. Depois use as questões para testar os casos especiais.

+400 J
+150 J
+250 J
Se Q = 0 e o meio externo realiza 300 J sobre o gás, então o trabalho realizado pelo gás é W = −300 J. Assim, ΔU = 0 − (−300) = +300 J.
Em um gás ideal isotérmico, ΔU = 0. Logo, Q = W. Se o gás realiza 250 J, deve receber 250 J de calor.
Como V é constante, W = 0. Portanto, ΔU = Q. Se o gás cede 180 J, Q = −180 J e ΔU = −180 J.
Num ciclo, ΔU = 0. Se o trabalho líquido é +700 J, então Q líquido = +700 J.
